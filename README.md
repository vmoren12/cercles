# Cercles

Ruletes de preguntes per a dinàmiques de cercle a l'aula.

**Obre l'aplicació:** https://vmoren12.github.io/cercles/

## Què fa

- **Ruleta o targetes** per triar una pregunta a l'atzar, o bé tria per número o des de la llista.
- **Tres modes de tria**: amb repetició, eliminant la pregunta que ha sortit o marcant-la com a feta.
- **Temàtiques editables**: crea, duplica, canvia el color o enganxa una llista de preguntes.
- **Preparar sessió**: tria preguntes de diverses temàtiques (o sorteja-les) per a la sessió del dia.
- **Mode projecció** a pantalla completa per a la pissarra digital.
- **Exportar i importar** en format `.json`: en exportar, tries si vols totes les temàtiques o només una (i quina). En importar, si ja hi ha una temàtica amb el mateix nom, pots triar si conserves la teva, la substitueixes o les mantens totes dues.

## On es desen les dades

Les ruletes es desen al navegador de l'ordinador on fas servir l'aplicació (`localStorage`); no s'envien enlloc. Per fer-les servir en un altre ordinador o navegador, exporta-les en un fitxer i importa'l allà. També és una bona manera de tenir-ne una còpia de seguretat.

## Ús en local

És un sol fitxer HTML sense dependències ni procés de compilació: n'hi ha prou d'obrir `index.html` amb el navegador.

## Desplegament

Es publica amb GitHub Pages a partir de la branca `main` (carpeta arrel). Cada canvi que s'hi puja s'actualitza automàticament a la web.
